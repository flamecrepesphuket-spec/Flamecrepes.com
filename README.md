# Flame Crepes Phuket

A premium, mobile-first Next.js homepage for FLAME CREPES Phuket.

## Stack

- Next.js App Router
- React
- TypeScript
- Tailwind CSS
- ESLint

## Scripts

```bash
npm run dev
npm run lint
npm run build
```

## Image placeholders

The homepage intentionally uses styled image placeholders in `components/ui/ImagePlaceholder.tsx` so real Flame Crepes photography can be added later under `public/images/` without using random external food photos.
